# moritatarvirdians.com

Personal site: academic work, the Morita DataLand YouTube channel, writing, and a coaching practice
that opens after the PhD defence.

Plain HTML and CSS. No framework, no build step, no dependencies. One optional Python script for
housekeeping. This is deliberate: AI crawlers do not run JavaScript, so server-rendered HTML is the
format that actually gets read and cited.

## Files

```
index.html            Home
research.html         Publications, projects, teaching, talks
videos.html           Morita DataLand
writing/              Blog index + posts
coaching.html         Coaching practice (dormant until 2027)
about.html            Bio, background, personal, press kit
404.html
feed.xml              RSS for writing/ — add an <item> per post
robots.txt            Everything allowed, including AI crawlers
sitemap.xml           Generated by tools/build.py
llms.txt              Optional AI-crawler summary
assets/css/style.css  Single stylesheet. All colours are tokens at the top.
assets/js/main.js     Theme toggle + nav highlighting. Site works without it.
assets/img/           Photos, favicon, OG card
assets/files/         CV PDF
_partials/            Shared header + footer, pushed into pages by build.py sync
tools/build.py        sync | sitemap | domain | check
```

## Everyday commands

```bash
python3 tools/build.py sync                 # edit _partials/, then push into every page
python3 tools/build.py sitemap              # after adding or removing a page
python3 tools/build.py check                # find leftover placeholders and broken local links
python3 tools/build.py domain example.com   # move to a different domain in one go
python3 tools/build.py all                  # all three
```

Preview locally:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Use the local server rather than opening the file directly. Every internal link is root-relative
(`/research.html`), which only resolves over HTTP.

## Deploying to GitHub Pages

1. Create a public repo named `moritadataland.github.io` (the name matters: a repo named
   `<username>.github.io` is served at the root, so links like `/research.html` work unchanged).
2. Push this folder to the `main` branch.
3. Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
4. Wait a minute. The site is live at `https://moritadataland.github.io/`.

If you use any other repo name, the site is served from a subfolder and every root-relative link
breaks. Either rename the repo or switch all links to relative paths first.

### Adding a custom domain later

1. Buy the domain (Cloudflare Registrar sells at cost, roughly €10 a year for a `.com`).
2. At the DNS provider, add four A records for the apex pointing at `185.199.108.153`,
   `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, and a CNAME for `www` pointing at
   `moritadataland.github.io`.
3. Create a file called `CNAME` in the repo root containing just the domain.
4. Settings → Pages → Custom domain → enter it → tick *Enforce HTTPS*.
5. Run `python3 tools/build.py domain yourdomain.com && python3 tools/build.py sitemap` so every
   canonical URL, OG tag and schema `@id` follows.

GitHub keeps redirecting `moritadataland.github.io` to the custom domain afterwards, so nothing is lost.

## Before you go live

Run `python3 tools/build.py check` and work through what it prints. In short:

- Replace every `class="ph"` placeholder block with a real `<img>`.
- Replace `REPLACE_ME` in the Google Scholar links and `0000-0000-0000-0000` with your ORCID.
- Replace `REPLACE_WITH_YOUR_FORM_ENDPOINT` on the two forms (see CONTENT-TODO.md).
- Add `assets/files/morita-tarvirdians-cv.pdf`.
- Add `assets/img/og-card.jpg` at 1200×630.

Then submit the sitemap in Google Search Console and Bing Webmaster Tools.

## Editing

Colours, fonts and spacing are all CSS custom properties in the `:root` block at the top of
`assets/css/style.css`. Change them there and the whole site follows, in both light and dark mode.

To add a blog post: copy `writing/nine-reasons-one-silence.html`, change the content and the JSON-LD,
add a row to `writing/index.html`, add an `<item>` to `feed.xml`, then run
`python3 tools/build.py sitemap`.
